# Spring Boot Backend Template
Questo progetto nasce come un template semplice ed essenziale per la creazione di backend in Java con Spring Boot.
L’obiettivo è avere una base chiara, ordinata e facilmente estendibile, da cui partire per sviluppare applicazioni più complesse.

Il template includerà:

- una struttura di progetto pulita e ben organizzata
- un semplice CRUD di esempio
- un sistema di registrazione e login
- buone pratiche di base per chi vuole imparare o avviare nuovi progetti più velocemente

Questo repository è pensato come punto di partenza, sia per chi sta iniziando con Spring Boot, sia per chi vuole un progetto iniziale da riutilizzare.
